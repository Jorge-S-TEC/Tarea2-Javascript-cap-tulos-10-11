10.7 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué:

  1. Falso. Para hacer referencia a una ubicación o elemento específico en un arreglo, especificamos el nombre del arreglo y el índice del elemento, no su valor.
  2. Verdadero. La declaración de una variable de arreglo reserva espacio lógico para el mismo.
  3. Falso. Para indicar que deben reservarse 100 ubicaciones para el arreglo p, se requiere instanciarlo correctamente (por ejemplo, var p = new Array(100);); la sintaxis p[100]; por sí sola no realiza dicha reserva de tamaño.
  4. Verdadero. Un programa de JavaScript que inicializa los elementos de un arreglo de 15 elementos en cero requiere iterar, conteniendo cuando menos una instrucción for.
  5. Verdadero. Un programa de JavaScript que calcula el total de los elementos de un arreglo bidimensional debe recorrer filas y columnas mediante instrucciones for anidadas.
